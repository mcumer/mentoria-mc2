## Data handling

**Does the plugin read personal data?** It uses relevant user and business
context the AI host makes available, including conversation content and supplied
material. That context can contain personal data. Do not answer “no personal
data” just because the package has no server. Instructions minimize the summary,
exclude irrelevant memories and third-party records, and do not request email
or other contact information in the AI conversation.

**Does the plugin store personal data?** The plugin has no database or remote
business storage and does not create Brand, Audience or Avatar records. Chat
history, memory or files generated at the person's request are governed by the
AI host's features and policies. Do not promise zero platform storage.

**Does it send data to another service?** The package contains no MCP, API call,
runtime script, account connection or automatic data transmission. On explicit
request for personal help, it can create an editable summary and provide a
fixed link to a separate website. The link contains no personal data or brief.
The person reviews, copies, pastes and submits the form themselves.

**What does the separate website do?** It receives name, email and chosen
summary, registers the request in the language-specific SnakeMember list, and
sends a notification through SnakeMember's existing SparkPost delivery. This
is a website flow with its own notice, not an undeclared connector invoked by
the plugin. The form also uses Google reCAPTCHA. No newsletter, booking or
purchase is automatically created by that request.

**Retention:** the plugin has no independent retention system; host retention
is governed by the selected AI platform. The website notice says request data
is kept while the request is handled and, if a relationship follows, during
that relationship. Do not invent a fixed number of days or deletion guarantees.

**Privacy reference:** [published website notice and optional contact flow](https://mikelmc2.com/privacidad#mentoria-contact).
Do not present that notice as the privacy policy of the AI platform.

**Intended use by under-18s:** no age-targeting declaration has been confirmed
by the owner. The product description targets experts and course creators;
that does not by itself justify answering an age/compliance attestation.

## Commercial behavior

The AI mentoring is free and completes its result without human intervention.
If the person asks, an optional contact form lets them request personal review,
mentoring or implementation help. The package does not accept payment, sell
an item or subscription, book a session, quote a price or guarantee that the
request will be accepted. Terms and any fee for personal services are agreed
separately with the owner. Personal help is not a condition for using MentorIA.

Use this exact behavior to answer the portal's commerce questions. Do not infer
that external services are always permitted, or that moving a payment outside
chat resolves every directory policy. The authorized owner completes the final
declaration and any required legal acknowledgements in the portal.
